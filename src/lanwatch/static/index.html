    Why some devices say "private MAC"

    Every network card ships with a vendor-assigned MAC. Modern phones, tablets and laptops replace it on Wi-Fi with a random one to stop tracking across networks. Random addresses set the locally administered bit, so the second hex digit is 2, 6, A or E (for example x2:.. or xA:..).

    lan-watch spots that bit, skips the vendor lookup (there is no vendor to find) and treats a new private MAC as "probably a phone you own" rather than an intruder: it is logged and summarised, not shouted about. A phone set to a fixed private address per network keeps it on your Wi-Fi, so once you mark it known it stays known. A device set to rotate shows up as new again; when it announces the same hostname, the timeline links it to the earlier entry.

    Hostnames come from the network and can be spoofed, so a matching name is a hint, never automatic trust.
